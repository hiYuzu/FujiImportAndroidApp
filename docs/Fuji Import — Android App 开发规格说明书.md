# Fuji Import 1.0 规格

## 目标与范围

面向小米 Pad 6S Pro + FUJIFILM X-T5，通过 USB-C 数据线完成“连接 → 浏览 → 选择 → 原文件导入”。中文原生界面，横屏优先，兼容竖屏和系统深浅主题。离线、无需 Root，不依赖富士官方 App 或运行时 ADB。

技术：Kotlin、Compose/Material 3、USB Host、MtpDevice、Coroutines/Flow、ViewModel/Repository、MediaStore、DataStore；保留 Gradle Wrapper，采用稳定依赖，核查第三方许可证。UI 与 USB 访问分层，优先保证真实读取与导入可靠性。

## 连接与扫描

- 启动扫描现有设备，监听插拔，按接口/协议识别并申请 USB 权限；连接成功自动扫描，断开释放资源，重连重新验证对象 Handle。
- 清楚区分未连接、识别、待授权、连接中、已连接、失败、断开；处理拒绝授权、接口占用、模式不兼容。优先使用现有相机设置，实际不兼容时再提示排查。
- 读取全部可访问存储，包括双卡；支持多目录、存储筛选与手动刷新。存储由设备实际报告，不硬编码 DCIM 或仅凭 VID/PID 判断能力。
- 后台增量扫描，逐步显示文件名、格式、大小、拍摄时间及存储信息；过滤无关文件，单文件失败不阻断扫描。

| 格式 | 列表 / 原文件导入 | 预览 |
|---|---|---|
| JPG/JPEG | 必须 | 必须 |
| RAF | 必须；与同名 JPEG 分别保留 | 尽可能支持 |
| HEIF/HIF | 必须 | 系统支持时 |

视频不属于 1.0 核心范围。

## 浏览与选择

- 自适应等尺寸网格、居中裁剪、日期分组，默认拍摄时间正序，可切换倒序并记住选择；显示总数与筛选条件。
- 仅按需异步加载可见缩略图，优先使用相机缩略图；内存/磁盘 LRU、有限读取并发，失败占位与重试。
- 全屏左右翻页、双指/双击缩放、放大拖动、单击显隐工具栏；返回保留网格位置。
- 高清图按需读取至私有缓存后采样/分块解码。RAF 可使用相机缩略图、JPEG 伴生或内嵌预览；受限时保留条目及导入能力，无需专业 RAW 显影。
- 信息展示文件名、格式、大小、时间、分辨率及可取得的相机型号、焦距、光圈、快门、ISO；字段来源为对象/EXIF。
- 长按多选、清晰选中标记与数量、全选当前筛选、取消全选/退出；列表与预览选择一致，预览可直接导入。

## 原文件导入

- 单张/批量流式复制，保留原字节、文件名及 EXIF；相机端始终只读。
- JPEG/系统支持的 HEIF 写入 MediaStore 的 `Pictures/FujiImport/`；RAF/不支持的 HEIF 写入 `Download/FujiImport/`。RAW 由文件管理器访问，相册可见性取决于系统支持。
- 待发布/临时写入，完成后校验实际大小，再发布并计成功；失败、取消、断线清理未完成文件。
- 显示队列进度、当前文件、准确可得的字节进度及成功/失败/跳过数量；支持取消。坏文件继续，空间不足或断线停止受影响操作，保留成功文件。
- 仅凭充分的源元数据、成功记录与本地文件存在性确认重复；确认后跳过，否则安全重命名，禁止覆盖已有文件。
- 本地记录文件名、大小、拍摄/导入时间、结果及 URI；列表标记有效的已导入文件，重启保留设置与记录。

## 页面与诊断

连接状态、相册、全屏预览、导入进度、设置/诊断。1.0.1 精简说明与重复文字，统一深浅配色、圆角、图标和留白；保留关键状态及操作反馈，以照片为主体。

设置包含目录、版本、缓存管理、USB 信息、连接错误和脱敏日志导出；错误使用简明中文。诊断不含照片、序列号或其他敏感信息。

## 稳定性与验收

- USB I/O 在后台串行或受控并发执行，协调缩略图与导入；断线取消相关任务，关闭句柄与临时资源。
- 1000 张及数千张场景无 OOM、网格可用；旋转与前后台切换保持关键状态。扫描、预览、导入速度以实测为准。
- 覆盖无卡/空卡、权限拒绝、接口占用、缩略图失败、坏文件、重复、空间不足、取消、断线和重启。
- MtpDevice 不兼容时先采集真实描述符及协议响应，再决定专用 PTP 适配。
- 交付源码、长期密钥签名的可安装 Release APK、简短文档及测试结果。真实设备完成连接、缩略图/大图、多选、JPEG/RAF 原文件导入、媒体库访问及重连流程，且无阻断使用的严重缺陷，才完成 1.0 验收。

开发与设备操作由 Codex 根据用户指令执行；已验证结果和待办分别见 [验证记录](本地验证记录.md)、[实机清单](实机验证清单.md)。
